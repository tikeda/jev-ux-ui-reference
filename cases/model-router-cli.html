CLI／モデルルーティング

Agent Router

契約中サービスを踏まえてモデルを選ぶCLI

判断型Choice推定 根拠公開投稿のみ

このUIがしていること

ユーザーはモデルを毎回手動選択せず、ルーティング結果だけ確認できる。CLIのため判断のログが残りやすい。

キャプチャ

見る箇所入力、判断結果の表現、判断後にユーザーまたはシステムが取る操作

入力から画面の変化まで

  1. 判断への入力

    作業内容、契約中のAIサービス、利用可能モデル、クォータ等。

  2. Jevの判断

    実行するエージェント／モデルと推論強度を選ぶ。

  3. 結果がUIをどう変えるか

    ターミナル上に選択モデル、理由に相当する入力情報、候補スコアを表示し、選択先へ処理を渡す。

判断型の見立て
Choice推定
「実行するエージェント／モデルと推論強度を選ぶ」という記述からの見立て。質問型は原文で確認されていない。

Jevとの適合

適合度が高い。候補が有限で判断結果が状態遷移へ直結する。誤選択時に再実行先を変えられるため比較的可逆。

確認範囲と未確認事項

公開投稿・動画・公開リポジトリへの掲載を確認。ローカル実行は未検証。

  • 確認済み上記出典で見える画面、投稿・READMEに明記された用途
  • 未検証実際の精度、速度、継続利用時の挙動、公開コードをローカル実行した結果
  • 推定扱いソースで質問型やプロンプトが公開されていない箇所
