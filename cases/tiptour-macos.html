macOSアプリ／操作対象選択

TipTour

自然言語からデスクトップ操作対象を選ぶMac UI

判断型Choice推定 根拠リポジトリ確認

このUIがしていること

判断結果を抽象的なテキストではなく、対象オブジェクトへ直接アンカーした操作候補として提示する。

キャプチャ

見る箇所入力、判断結果の表現、判断後にユーザーまたはシステムが取る操作

入力から画面の変化まで

  1. 判断への入力

    短い操作要求、デスクトップ上の候補ターゲット。

  2. Jevの判断

    操作対象と実行アクションを選ぶ。

  3. 結果がUIをどう変えるか

    画面上の候補にMove / Merge / Add / Guide等の操作チップを重ねる。

判断型の見立て
Choice推定
「操作対象と実行アクションを選ぶ」という記述からの見立て。キャプチャだけではJev判断と別モデル生成の境界を確定できない。

Jevとの適合

条件付きで高適合。対象候補が有限なら強いが、スクリーンショットだけではJev判断と別モデル生成の境界を確定できない。

確認範囲と未確認事項

公開リポジトリとREADMEキャプチャを確認。Jevモードと別のGemini音声モードがあるため役割を混同しない。

  • 確認済み上記出典で見える画面、投稿・READMEに明記された用途
  • 未検証実際の精度、速度、継続利用時の挙動、公開コードをローカル実行した結果
  • 推定扱いソースで質問型やプロンプトが公開されていない箇所
